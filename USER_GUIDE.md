# Domain Graph Analyzer — руководство пользователя

Инструмент для анализа доменных схем: строит граф связей между доменами, ищет проблемы (циклы, битые ссылки, изоляцию), поддерживает работу с локальной директорией и удалённым сервером.

## Быстрый старт

**Локальный режим** — если схемы уже лежат на диске:

```bash
node graph-analyzer.js ./domains 3000
```

**Удалённый режим** — скачать схемы с сервера:

```bash
node graph-analyzer.js --server https://your.site.url --login login --password "password"
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

---

## Режимы работы

### Локальный режим

Скрипт читает все `.ro` файлы в указанной директории (рекурсивно), парсит YAML и строит граф.

```bash
node graph-analyzer.js <directory> [port]
```

- `<directory>` — путь к директории с `.ro` файлами (обязательно)
- `[port]` — порт веб-сервера (по умолчанию 3000)

### Удалённый режим

Скрипт логинится на сервер, скачивает структуру папок и все ENABLED-домены, сохраняет в локальный кэш, а затем работает с ним как с обычной директорией.

```bash
node graph-analyzer.js --server <url> --login <user> --password <pass> [options]
```

**Что происходит:**
1. Логин → получаем accessToken
2. Загрузка структуры папок (REST/GraphQL)
3. Загрузка списка доменов со статусом ENABLED
4. Скачивание `sourceCode` каждого домена → сохранение в кэш с сохранением структуры папок
5. Запуск веб-сервера на локальном кэше

## CLI-аргументы

| Флаг | Описание |
|------|----------|
| `--server <url>` | Базовый URL сервера` |
| `--login <user>` | Имя пользователя для логина |
| `--password <pass>` | Пароль (в кавычках) |
| `--port <port>` | Порт веб-сервера (по умолчанию 3000) |
| `--refresh` | Принудительно обновить кэш |
| `--reset-cache` | Удалить кэш перед загрузкой |
| `--secure` | Проверять TLS-сертификат (по умолчанию отключено для self-signed) |
| `--help` | Показать справку |

**Примеры:**

```bash
# Первый запуск — скачает и закэширует
node graph-analyzer.js --server https://your.site.url --login admin --password "qwerty"

# Повторный — используется кэш
node graph-analyzer.js --server https://your.site.url --login admin --password "qwerty"

# Принудительное обновление кэша
node graph-analyzer.js --server https://your.site.url --login admin --password "qwerty" --refresh

# Полный сброс кэша и загрузка заново
node graph-analyzer.js --server https://your.site.url --login admin --password "qwerty" --reset-cache
```

## Кэш

**Расположение:** `.cache/domains/<hostname>__<hash>/` рядом с `graph-analyzer.js`.

Для сервера `https://your.site.url` это будет:

```
.cache/domains/your.site.url__11dbb506/
```

**Структура:**

```
.cache/domains/your.site.url__11dbb506/
├── .complete                      # маркер успешной загрузки
├── _index.json                    # метаданные: папки, домены, время
├── _errors.json                   # если были ошибки при загрузке
├── sgrc/
│   ├── audit/
│   │   └── domains/
│   │       └── sgrc.evo.compliance.audit.ro
│   ├── safeguards/
│   │   └── domains/
│   │       └── sgrc.evo.safeguards.ro
│   └── ...
└── isassets/
    └── domains/
        └── it.assets.rvision.ru.ro
```

**Поведение кэша:**

- **Есть валидный кэш** → используется без запросов к серверу
- **Есть кэш, но `--refresh`** → перезакачивает
- **Есть кэш, но `--reset-cache`** → удаляет и закачивает заново
- **Нет кэша** → закачивает

Когда страница открывается из кэша, в правом верхнем углу появляется жёлтый тост с датой кэша и готовой командой для его обновления.

**Добавьте `.cache/` в `.gitignore`**, чтобы случайно не закоммитить скачанные схемы.

## Сайдбар

Секции сайдбара (можно свернуть кнопкой `‹` в шапке):

- **Обзор** — узлы, связи, missing, broken
- **Связность** — домены, изолированные, linkage, FQID, циклы
- **Топ по связям** — 5 самых подключённых доменов (клик центрирует)
- **Стена позора** — 5 доменов с минимальным health score
- **Неймспейсы** — распределение доменов по семействам (клик — фильтр)
- **Теги** — облако тегов
- **Избранное** — закладки
- **Легенда** — что означают цвета

## Граф

### Типы узлов

| Цвет / иконка | Тип | Значение |
|---------------|-----|----------|
| Зелёный ● | Domain | Корректный домен |
| Оранжевый ▲ | Missing | Ссылка на несуществующий домен |
| Красный ✕ | Broken | Файл, который не удалось распарсить |

### Типы связей

| Цвет | Тип | Значение |
|------|-----|----------|
| Сине-фиолетовый пунктир | Linkage | Явная связь из `linkages` |
| Зелёный | FQID | Неявная ссылка через FQID |
| Жёлтый | Selected | Выделенная связь |
| Оранжевый | Cycle | Связь внутри цикла |
| Красный | Violation | Нарушение правила |

### Звёздочка ★

У узла слева от ID — узел добавлен в избранное.

### Цифра в правом верхнем углу узла

**Health score** от 0 до 100: чем больше, тем здоровее домен.

## Фильтры

Меню **⚙️ Фильтры** содержит:

- **Тип узлов** — Domain, Missing, Broken (вкл/выкл)
- **Тип связей** — Linkage, FQID
- **Namespace** — текстовое поле с поддержкой масок

### Синтаксис namespace-фильтра

| Паттерн | Что делает |
|---------|-----------|
| `sgrc.evo.*` | Все домены внутри `sgrc.evo` |
| `users.rvision.ru` | Только этот домен |
| `sgrc.*, users.*` | Несколько масок через `,`, `;` или пробел |
| `!test.*` | Исключить домены из `test.*` |
| `sgrc.*, !sgrc.legacy.*` | Включить `sgrc.*`, кроме legacy |

Кнопка «Сбросить» очищает всё.

## Поиск

Открывается по **Shift+Tab**, **Ctrl/Cmd+K** или кнопкой 🔍 в тулбаре.

Ищет по полям: **id**, **name**, **description**, **tags**. Совпадения подсвечиваются жёлтым, рядом с полем — бейдж (`id`, `name`, `tags`, `description`).

Управление:

- `↑` / `↓` — навигация
- `Enter` — перейти к домену
- `Esc` — закрыть

Если найден один результат — можно сразу `Enter`.

## Анализ

### 🔁 Найти циклы

Находит все циклические зависимости между доменами (алгоритм Tarjan для SCC). Подсвечивает узлы и рёбра оранжевым. В тулбаре показывается бейдж с числом групп.

Повторный клик снимает подсветку.

### ◯ Только изолированные

Фильтр, оставляющий только домены без связей.

### 🗂 Агрегация по семействам

Схлопывает домены в неймспейсы (первый + второй сегмент id). Между семействами — одно ребро с числом связей. Внутренние связи скрываются.

### 🎯 Фокус

Двойной клик по узлу: всё, кроме окружения до N шагов, гаснет. Глубина N — в меню Анализ (1–4). Или через контекстное меню.

### ⛔ Правила зависимостей

Позволяет задать ограничения вида `ui.* → db.*` со статусом Warn (жёлтый) или Forbid (красный). Нарушения подсвечиваются, попадают в отчёт.

Правила хранятся в localStorage.

## Вид

- **Раскладка** — LR (горизонтально), TB (вертикально), Force-directed, Circular
- **Heatmap** — раскраска узлов по метрике: Health, Связи, Entities, FQID-ссылки
- **Компактный режим** — узлы в виде маленьких кружков
- **Группировка в рамки** — визуальные прямоугольники вокруг неймспейсов
- **Объединять A↔B** — двунаправленные связи одним ребром
- **Подписи связей** — постоянно показывать подписи (иначе только на hover)
- **Тема** — тёмная / светлая

## Данные

- **💾 Экспорт в JSON** — сохранить полный граф (не видимую часть)
- **📝 Отчёт в Markdown** — сгенерировать отчёт со сводкой, топами, циклами, битыми ссылками
- **🖼️ Экспорт в PNG** — снимок текущего вида графа
- **⇄ Diff** — загрузить ранее сохранённый JSON и увидеть изменения (зелёные — добавленные, красные — удалённые)

**Как делать diff:**

1. Экспорт JSON → сохранился файл `domain-graph-...json`
2. Через время повторите экспорт
3. Откройте `⇄ Diff`, загрузите первый файл
4. В тулбаре появится легенда: `+Nn / +Ne` и `−Nn / −Ne`

## Работа с узлами

### Клик по узлу

Открывает боковую панель с деталями: id, name, version, description, tags, health, FQID-ссылки, входящие/исходящие связи.

Вкладка «📄 Файл» — содержимое `.ro` файла в редакторе Monaco.

### Двойной клик

Focus mode — подсветить только окружение этого узла.

### Ctrl/Cmd + клик

Добавить в выделение для построения пути.

### Правая кнопка

Контекстное меню:

- **🎯 Фокус (N шагов)** — то же, что двойной клик
- **📊 Что зависит от него** — расширенный фокус (3 шага)
- **🛤️ Путь от...** — выберите начальный узел, затем кликните целевой
- **↪️ Путь до...** — то же, наоборот
- **📂 Открыть файл**
- **📋 Копировать ID**
- **★ В закладки**
- **👁 Скрыть**

### Path finder

Два способа:

1. **Ctrl+клик** на двух узлах → кнопка «🛤️ Найти путь» в тулбаре
2. **ПКМ → Путь от/до** → клик по второму узлу (без Ctrl)

Путь подсвечивается жёлтым. Esc снимает.

### Закладки

ПКМ → «★ В закладки» или клавиша `B` при выделенном узле. Кнопка `★` в тулбаре показывает только избранные. Закладки сохраняются в localStorage.

## Troubleshooting

### «html2canvas не загружен» при экспорте PNG

Проверьте Network в DevTools. Если CDN заблокирован — используйте системный скриншот или настройте прокси.

### «EADDRINUSE: address already in use :::3000»

Порт 3000 занят другим процессом:

```bash
lsof -ti:3000 | xargs kill -9
```

Или используйте другой порт: `--port 4000`.

### Тултипы не появляются

Проверьте кнопку `💬` в тулбаре — не отключены ли они.

### Граф пустой после фильтров

Проверьте:

- Все чипы в меню «Фильтры» активны
- Поле Namespace пустое или корректное
- Кнопка «★ Показать только избранные» не активна
- Кнопка «◯ Изолированные» не активна

### Пропала связь между доменами после обновления

Кэш устарел. Запустите с `--refresh`.

### Не находит missing-домены

В кэше нет файла этого домена, потому что он не имеет статуса ENABLED на сервере. Проверьте источник.
```
