# Domain Graph Analyzer

Инструмент для анализа доменных схем: строит граф связей между доменами, находит циклы, битые ссылки, узкие места архитектуры, помогает планировать порядок установки. Работает с локальной директорией или скачивает схемы с сервера.

![Node](https://img.shields.io/badge/node-%3E%3D18-blue)

## Возможности

- 🕸️ **Интерактивный граф** доменов и связей (ReactFlow + Dagre)
- 🔍 **Поиск** по id, name, description, tags
- 🎯 **Фильтры** по типам узлов, связям, namespace-маскам с поддержкой `!` (исключение)
- 🔁 **Поиск циклов** (Tarjan SCC) — прямые и длинные
- 🛤️ **Path finder** — кратчайший путь между двумя доменами
- 🎯 **Focus mode** — окружение узла до N шагов
- 📦 **Топологическая сортировка** — порядок установки доменов с уровнями
- ⛔ **Правила зависимостей** — запреты и предупреждения между неймспейсами
- 🔍 **Массовая валидация** — проверка доменов через API с отчётом
- 📊 **Health score** — оценка «здоровья» каждого домена
- 🔥 **Heatmap** — раскраска по метрикам (health, связи, entities, FQID)
- 💾 **Экспорт** — JSON, Markdown, PNG
- ⇄ **Diff** — сравнение двух снимков графа
- ★ **Закладки** — избранные домены
- 📖 **Встроенная справка** (F1)

## Быстрый старт

```bash
npm install
node graph-analyzer.js ./domains 3000
```

Откройте [http://localhost:3000](http://localhost:3000).

### Удалённый режим

Скачивает схемы с сервера и кэширует локально:

```bash
node graph-analyzer.js \
  --server https://your.site.url \
  --login admin \
  --password "qwerty"
```

Повторные запуски используют кэш. Обновить: `--refresh`. Полный сброс: `--reset-cache`.

## CLI

| Флаг | Описание |
|------|----------|
| `--server <url>` | Базовый URL сервера |
| `--login <user>` | Имя пользователя |
| `--password <pass>` | Пароль |
| `--port <port>` | Порт веб-сервера (по умолчанию 3000) |
| `--refresh` | Принудительно обновить кэш |
| `--reset-cache` | Удалить кэш и загрузить заново |
| `--secure` | Проверять TLS-сертификат |
| `--help` | Справка |
